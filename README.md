# data_augmentation
## augment_videos.py

Пакетная аугментация MP4 через FFmpeg. Зеркалирование (`hflip` / `vflip` / `transpose`)
не применяется никогда — текст в кадре остаётся читаемым; это проверяется перед каждым
запуском FFmpeg. Микро-поворот (`rotate`) разрешён: он не зеркалит кадр.

Требования: Python 3.9+, `ffmpeg` и `ffprobe` в PATH (для `--captions-file` — сборка
с `libfreetype` и системный TTF-шрифт).

```bash
python augment_videos.py ./input ./output --variants 5 --workers 4 --seed 42
```

```bash
python augment_videos.py ./input ./output --frame-style on --captions-file texts.txt --nvenc
```

### Что делает каждый вариант

| Группа | Трансформация |
| --- | --- |
| Контейнер | удаление всех метаданных и глав, подстановка случайного профиля Apple iPhone 14/15/16 Pro (`com.apple.quicktime.make/model/software`) и `creation_time` за последние 48 часов |
| Кодек | `crf = max(14, --crf ± 1)`, случайный GOP 48–120, `libx264` или `h264_nvenc` (`-cq`) |
| Время | обрезка 0.2–0.6 с в начале и/или в конце (для роликов длиннее 4.5 с), ускорение в 1.015–1.045 раза |
| Пространство | плавный синусоидальный зум 1.04–1.09 (`scale` с `eval=frame`) + микро-поворот на 0.5–1.3° с центральным кропом |
| Рамка | опционально: кадр уменьшается до 91–95 % и ложится по центру на размытую (`gblur=sigma=25`), отмасштабированную и затемнённую копию потока |
| Цвет | сдвиг контраста / гаммы / насыщенности на 4–9 %, сдвиг оттенка на ±4°, `unsharp=5:5:0.35:5:5:0.0` |
| Текстура | зерно `noise` (яркость 5–9, цветность 2–4 — переживает квантование H.264), мягкая виньетка со случайным углом |
| Звук | сдвиг высоты тона на ±1.8–3.5 % с компенсацией темпа, 2–3 полосовых `equalizer` (200–400 / 1000–2500 / 4000–7000 Гц, ±2–4 дБ), подмешанный розовый шум, битрейт AAC 128k/160k/192k |
| Текст | опционально: случайная строка из файла через `drawtext` в верхней или нижней безопасной зоне |

Зум автоматически поднимается выше геометрического минимума для выбранного угла поворота,
поэтому чёрные углы не появляются ни при каком соотношении сторон.

### Аргументы

```
--variants N          вариантов на файл (по умолчанию 3)
--workers N           параллельных процессов ffmpeg (по умолчанию 2)
--seed N              seed для воспроизводимости
--crf N               базовое качество (к нему добавляется ±1), по умолчанию 18
--preset NAME         пресет кодировщика
--nvenc               кодировать через h264_nvenc вместо libx264
--frame-style off|on|random   фоновая рамка (по умолчанию random — 50 %)
--captions-file PATH  файл с текстами: случайная непустая строка на вариант
--font PATH           TTF для drawtext (по умолчанию ищется системный)
--recursive           искать MP4 в подпапках
```

### Манифест

Все применённые параметры, информация об исходнике, полная команда FFmpeg и SHA-256
входа и выхода пишутся в `output/manifest.jsonl` — любой вариант воспроизводим, а разметку
исходника можно связать с его аугментациями.
